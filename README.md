## ⚙️ Installation & Setup

Clone the repository

```
git clone https://github.com/your-username/react-chatbot.git
```

Go to the project folder

```
cd react-chatbot
```

Install dependencies

```
npm install
```

Run the development server

```
npm run dev
```

Open in browser

```
http://localhost:5173
```
